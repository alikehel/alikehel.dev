Everything I use to build things, from my desk to my terminal. Curious what other developers use? [uses.tech](https://uses.tech) collects hundreds of pages like this one.

## Hardware

- **Laptop:** MacBook Pro 14-inch, M4, 16 GB RAM, 512 GB, Space Black
- **PC:** AMD Ryzen 5 4600G on an Asus TUF Gaming B450-Plus II, 16 GB DDR4-3600 (TeamGroup Vulcan Z), Samsung 970 Evo Plus 500 GB NVMe, in an ADATA XPG Invader case with an XPG Core Reactor 650 W power supply
- **Monitor:** ASUS TUF Gaming VG249Q3A-W
- **Keyboard:** Redragon K552 wired mechanical
- **Mouse:** Logitech G305 Lightspeed wireless
- **Audio:** HyperX Cloud Stinger Core headset and Samsung Galaxy Buds FE
- **Phone:** Samsung Galaxy A52s, 128 GB

## Editor and terminal

- **Editor:** Visual Studio Code, with the Oxc extension for linting and formatting
- **Theme:** Paddy (Ultramarine)
- **Font:** JetBrains Mono
- **Terminal:** the built-in macOS Terminal, with zsh

## Development

- **Languages:** TypeScript and JavaScript
- **Frontend:** React, TanStack Start and Router, Tailwind CSS
- **Backend:** Node.js
- **Databases:** PostgreSQL, MySQL and SQLite (Cloudflare D1)
- **Testing:** Vitest and Playwright
- **Tooling:** Vite+, pnpm, Docker, Git and GitHub
- **AI:** Claude Code, with Opus
- **Hosting:** Cloudflare. This site runs on Workers, and my domain and files like my resume live there too
